            Importar traçado do Moovit

            1. Uma vez só: arraste o botão abaixo para a barra de favoritos do navegador.

              Exportar para o BuzuRota

              Não clique nele aqui: ele só funciona dentro do editor do Moovit. Se a barra de favoritos estiver escondida, use Ctrl+Shift+B.
            2. Entre no editor do Moovit, abra a linha e clique na viagem ativa do dia que você quer (a página da viagem tem o endereço /editor/trip/…).
            3. Clique no favorito Exportar para o BuzuRota. Vai baixar um arquivo moovit-LINHA-….json.
